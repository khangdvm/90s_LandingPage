# Đối chiếu yêu cầu và nội dung công khai

Nguồn: checkout hiện có `/workspace/90s_LandingPage`, giữ React/Vite, Express, Prisma/PostgreSQL. Không dùng ZIP cũ, không thêm nghiệp vụ đặt phòng/thanh toán/lưu yêu cầu tư vấn.

| Nhóm yêu cầu             | Thực hiện                                                                                                                                                          | Bằng chứng kiểm thử / giới hạn                                                                                                                                                                        |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. Giữ nền tảng, dữ liệu | Migration cộng thêm; seed upsert `update: {}`; không reset                                                                                                         | Test schema cũ → migration mới và cài mới trên DB riêng; không chạy trên production                                                                                                                   |
| 2. URL đúng mục đích     | `shared/content.js` dùng ở frontend, backend và renderer; ảnh khác CTA, liên hệ, điện thoại                                                                        | Regression ba lỗi Zalo/ảnh/CTA, scheme nguy hiểm, traversal, URL có credentials                                                                                                                       |
| 3. Upload                | `server/src/routes/uploads.js`; `ContentEditors.jsx`; JPEG/PNG/WebP ≤8 MB; Sharp giải mã, giới hạn 40 triệu pixel, xoay/resize/tái mã hóa WebP; UUID; API xác thực | API kiểm tra chưa đăng nhập, giả ảnh, SVG, quá dung lượng, ảnh thật + header CORP; browser upload/preview/gallery; không có tự xóa file                                                               |
| 4. Phạm vi CMS           | Settings: thương hiệu/logo/footer/section/thông báo/cà phê/trạng thái xác nhận; section rỗng hoặc tắt được bỏ khỏi nav                                             | Browser sửa section/brand/notice, tắt cà phê, section rỗng; nhãn mẫu mặc định bật. Xác nhận áp dụng toàn website, không theo từng bản ghi                                                             |
| 5. Bài viết              | Editor các khối heading/paragraph/list/image, đậm/nghiêng/liên kết và preview; React render văn bản, không inject HTML                                             | Browser preview chuỗi script không thực thi, đăng/gỡ đăng, slug ổn định; API chặn liên kết nguy hiểm. Định dạng theo khối, không phải trình xử lý văn bản đầy đủ; ngày chỉ để hiển thị, không hẹn giờ |
| 6. Thực đơn              | `menuItems` JSON có tên/giá nullable/đơn vị/mô tả/ảnh/hiển thị/thứ tự; migration chuyển `dishes` giữ tên gốc                                                       | API và browser phân biệt null/0; editor thêm/xóa/đưa lên; dữ liệu cũ `dishes` còn nguyên                                                                                                              |
| 7. Detail và 404         | `/phong/:slug`, `/tin-tuc/:slug`, gallery, API chỉ lấy active/published; metadata/canonical                                                                        | Browser direct URL/refresh/Back, room ẩn, news nháp, đường dẫn sai; CSR cần hosting fallback, social crawler có thể không chạy JS                                                                     |
| 8. Chống mất nội dung    | `useDraft.jsx`; localStorage theo tài khoản + resource/ID; URL giữ màn hình edit; beforeunload, chặn router/cancel; version check khi PATCH                        | Browser refresh/401/login/restore, điều hướng và conflict settings; JWT vẫn 2 giờ. Bản nháp ở trình duyệt hiện tại, không đồng bộ thiết bị; trình duyệt quyết định có hiện beforeunload               |
| 9. Danh sách             | Server page/limit/search/status/category/section; total; sortOrder+ID hoặc date+ID; thumbnails                                                                     | API phân trang không trùng, search/status; browser category/CRUD/error; UI tự clamp trang sau xóa                                                                                                     |
| 10. Responsive           | Ảnh lỗi thay thế; room sidebar tối đa 3 phòng, xem tất cả vẫn đủ; gallery cuộn, form/table responsive                                                              | Chromium tại 320/375/768/1440 px; nhiều loại form và section, lỗi DB thật và retry; không tuyên bố đã test Safari/Firefox                                                                             |

QA thật              | `server/test/*.test.js`, `tests/*.spec.js`                                                                                                                         | Xem `KET-QUA-KIEM-THU.md`; sử dụng PostgreSQL/Chromium thật, không thay API bằng mock                                                                                                                 |

## Nội dung nào sửa ở đâu

| Nội dung public                                                                       | Màn hình CMS                               | Ghi chú                                                                                  |
| ------------------------------------------------------------------------------------- | ------------------------------------------ | ---------------------------------------------------------------------------------------- |
| Tên thương hiệu, logo header/footer                                                   | Cài đặt → Tên thương hiệu, URL logo/upload | Logo upload được lưu độc lập build                                                       |
| Title/description website                                                             | Cài đặt                                    | Metadata mặc định trang chủ; detail lấy nội dung tương ứng                               |
| Hero ảnh/title/eyebrow/badge/CTA/thứ tự/bật tắt                                       | Hero / Slider                              | CTA section, route chi tiết, HTTP(S)                                                     |
| Giới thiệu và ảnh trang về 90s                                                        | Nội dung → Trải nghiệm                     | Tiêu đề/đoạn văn/CTA/ảnh                                                                 |
| Tiêu đề/phụ đề/mô tả từng section                                                     | Cài đặt → tên section                      | Để trống giữ nội dung giới thiệu mặc định; các thẻ chi tiết vẫn sửa độc lập              |
| Bật/tắt section                                                                       | Cài đặt → Hiển thị                         | Đồng bộ nav; section không có bản ghi được ẩn                                            |
| Phòng tên/slug/giá/sức chứa/giường/view/số lượng/mô tả                                | Phòng nghỉ                                 | Số lượng mô tả hạng, không phải phòng trống                                              |
| Phòng ảnh chính/gallery/thứ tự                                                        | Phòng nghỉ                                 | Ảnh chính riêng; gallery đưa lên/xóa; collage cũ giữ tham số nhưng không bắt admin chỉnh |
| Nhà hàng nhóm món/ảnh/CTA                                                             | Nội dung → Nhà hàng                        | Mỗi card là nhóm thực đơn                                                                |
| Từng món tên/giá/đơn vị/mô tả/ảnh/hiển thị/thứ tự                                     | Nội dung → Nhà hàng → Thực đơn             | Trống khác giá 0; nhãn trống ở Cài đặt                                                   |
| Cà phê nội dung/ảnh/CTA                                                               | Nội dung → Cà phê                          | Nhãn trạng thái ở Cài đặt                                                                |
| Ưu đãi/quyền lợi/điều kiện/ảnh/CTA                                                    | Nội dung → Ưu đãi                          | Cần chủ website xác nhận trước công khai                                                 |
| Tin category/title/slug/excerpt/body/ảnh/date/link/nháp                               | Tin tức                                    | Body cũ nguyên văn, khối mới được ưu tiên nếu có                                         |
| Hotline/Zalo/Facebook/địa chỉ/map                                                     | Cài đặt                                    | Placeholder không thành link hoạt động                                                   |
| Footer giới thiệu                                                                     | Cài đặt → Nội dung footer                  | Copyright theo năm + thương hiệu                                                         |
| Cảnh báo mẫu/thông báo kinh doanh                                                     | Cài đặt → Trạng thái xác nhận, Thông báo   | Mặc định chưa xác nhận; chỉ chủ website quyết định chuyển trạng thái                     |
| Nhãn nút UI (Lưu, Hủy, Nhận tư vấn...), hướng dẫn sử dụng, bộ lọc view, nhãn thống kê | Mã ứng dụng                                | Đây là UI ổn định, không cho sửa HTML/CSS hoặc pagebuilder                               |
