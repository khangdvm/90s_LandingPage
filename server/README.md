# Backend CMS 90s Homestay

Hướng dẫn cài mới, nâng cấp giữ dữ liệu, cấu hình PostgreSQL, upload bền vững, API và kiểm thử nằm trong [README gốc](../README.md).

Chạy các lệnh Prisma từ thư mục này để dùng `server/.env`. Backend cần cả thư mục `shared/` ở cấp repo. Không đưa `.env`, database hoặc ảnh upload vào ZIP mã nguồn. Không chạy seed hoặc migrate reset để nâng cấp.
